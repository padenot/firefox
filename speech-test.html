Speech Recognition Available Test

This page tests the SpeechRecognition.available() method to verify that the HWInference utility process starts correctly.

Expected behavior:

  • The utility process should start in the background
  • You should see printf output in the Firefox console/logs showing:
    • "HWInferenceTest: Starting utility process test"
    • "HWInferenceParent: Constructor called - parent actor created"
    • "HWInferenceParent: Bind called - IPC connection established"
    • "HWInferenceTest: HWInference utility process started successfully"
    • "HWInferenceTest: Making test call to RunInference"
    • "HWInferenceChild: RunInference called with model: test-model, input: test-input"
